# 🌐 Tasneem Ibrahim — Interactive Portfolio Website

An interactive, high-aesthetic web portfolio showcasing **30+ production repositories** across Generative AI, ReAct Agents, RAG Pipelines, Computer Vision, Data Engineering, and Systems Software.

Built with **HTML5, Modern Vanilla CSS, and JavaScript**.

---

## ✨ Features

- 🎨 **Glassmorphism Dark Theme**: Obsidian color palette with neon indigo and cyan accents.
- ⚡ **Live Search Engine**: Instant multi-attribute search matching titles, technical tags, and concepts.
- 🏷️ **Dynamic Category Filtering**:
  - **Generative AI & Agents**
  - **Machine Learning & Computer Vision**
  - **Data Engineering & Databases**
  - **Software Systems & Architecture**
- 🌟 **Featured Innovation Showcases**: Highlight cards with architecture bullet points and direct GitHub links.
- 🔍 **Interactive Deep-Dive Modals**: Inspect technical highlights, full tag stacks, and repository links.
- 📱 **Mobile & Desktop Responsive**: Optimized for ultra-fast load times with zero heavy frontend framework dependencies.

---

## 🚀 Quick Start (Local Preview)

Run a lightweight local HTTP server:

```bash
# Using Python
python -m http.server 8000
```

Then open `http://localhost:8000` in your web browser.

## 🌍 Free Deployment to GitHub Pages

To make this live on your custom GitHub URL (`https://tasneemibrahim-ai.github.io`):

1. Create a new repository on your GitHub account named:
   ```text
   tasneemibrahim-ai.github.io
   ```
2. Initialize and push this folder:
   ```bash
   cd tasneem-portfolio
   git init
   git add .
   git commit -m "feat: initial release of personal portfolio website"
   git branch -M main
   git remote add origin https://github.com/tasneemibrahim-ai/tasneemibrahim-ai.github.io.git
   git push -u origin main
   ```
3. GitHub Pages will automatically deploy your live portfolio at `https://tasneemibrahim-ai.github.io`!
